## Summary

This release resolves serverless execution timeouts during AI card generation through Server-Sent Events (SSE) streaming, fixes misleading provider error masking where OpenRouter issues displayed Gemini errors, restores the full OpenRouter model cascade with `openrouter/free`, standardizes 25s timeouts across providers, and establishes permanent versioning and agent protocols for Revia AI.

---

## What Changed

### 1. SSE Streaming Card Generation
- Converted card generation endpoint (`/api/v1/generate/cards`) to stream generated cards progressively using Server-Sent Events (`text/event-stream`).
- Cards are validated with Zod and streamed to the client the moment each card is parsed.
- Client UI accumulates and renders cards in real-time, eliminating the risk of Vercel serverless `FUNCTION_INVOCATION_TIMEOUT` on large batches.

### 2. Transparent Non-Masking Error Reporting
- In `AIGenerationService.generateStream()`, previously when the primary provider (e.g. OpenRouter) failed and the fallback provider (Gemini) also failed, the fallback error was thrown directly. This masked OpenRouter errors and caused the UI to show Gemini errors even when OpenRouter was selected.
- Updated error handling to preserve the primary error: if both providers fail, a composite error clearly reports both:
  `OPENROUTER failed: <primaryError>. (Fallback gemini also failed: <fallbackError>)`

### 3. OpenRouter Free Model Routing & Resilience
- Restored `"openrouter/free"` as the primary model in `OpenRouterProvider`.
- Restored complete candidate fallback cascade:
  1. `openrouter/free`
  2. `google/gemma-4-31b-it:free`
  3. `google/gemma-4-26b-a4b-it:free`
  4. `deepseek/deepseek-v4-flash-0731:free`
  5. `qwen/qwen3.8-27b:free`
  6. `liquid/lfm-2.5-2.6b:free`
  7. `nvidia/nemotron-3.5-lightning:free`
- Restored provider timeout defaults to 25s (`25000ms`) so shared free pools on OpenRouter have sufficient time to respond under load.

### 4. Gemini Provider Configuration
- Kept `gemini-3.6-flash` as default model (or `process.env.GEMINI_MODEL`).
- Restored provider timeout default to 25s (`25000ms`).

### 5. Automated Agent Versioning & Logging Protocol
- Documented release protocol in `AGENTS.md`, `CLAUDE.md`, and `GEMINI.md` to ensure any AI agent maintains logs and versioning on every release rather than making ad-hoc commits.
