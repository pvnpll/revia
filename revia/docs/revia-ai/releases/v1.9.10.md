## Summary

Fixed a "blank screen" bug in the AI session viewer that occurred when a user swiped through the AI-generated cards faster than the background pre-fetch could supply new ones.

---

## What changed

### Out-of-Bounds Handling (`ai-session-viewer.tsx`)
- With the batch size reduced to 5 (v1.9.8), fast swipers could reach `currentIndex == cards.length` while the next batch was still streaming.
- Previously, `StudyCardViewer` would attempt to render `cards[currentIndex]`. Finding `undefined`, it returned `null`, resulting in a blank white screen.
- Added a dedicated `isWaitingForCards` conditional render. If the user outpaces the generator, the viewer is safely unmounted and a `"Generating next batch..."` loading screen is shown until the new cards stream in.
- Added graceful error boundary: If the background fetch fails and the user reaches the end of the queue, they now see a "Failed to load more cards" error state with a "Try Again" button, rather than a blank screen.

---

## Verification
- Fast-swiping through an active session now gracefully shows the loading spinner instead of a blank page. Error states correctly display when network is disconnected.
