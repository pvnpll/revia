## Summary

This patch fixes all five gesture and rating issues in the study card viewer (Fix #3): swipe double-commit races, unreadable rating labels, unscrollable long answers in swipe mode, review-mode scroll-vs-navigate conflicts, and invisible edge-tap zones. **This release is on `develop` only** — it has not been merged to `main` and is not in production.

## Fixed

- **Swipe double-commit race (3d)** — Rapid double-flicks could advance two cards instead of one. The commit timer is now stored in a ref, cleared before rescheduling, guarded by `isExiting`, and cleaned up on unmount.
- **Rating buttons (3c)** — Numbers and labels lived in two disconnected grids with 9px micro-labels. Each button is now self-labeled (number + short label stacked, `h-16`), with `aria-label` for screen readers.
- **Swipe-mode scroll trap (3a)** — Revealed cards used unconditional `touch-none`, making long answers unreachable. The card now uses `touch-pan-y` once revealed so vertical scrolls scroll while horizontal drags still swipe.
- **Review scroll-vs-navigate conflict (3e)** — Vertical swipes in Daily Review fired navigation even when scrolling the answer pane. Navigation now only fires when the answer pane is at its scroll edge (or the gesture started outside it). Touch handlers moved from the fullscreen root to `<main>`; swipe mode no longer attaches them.
- **Edge-tap zones (3b)** — Invisible 25% prev/next zones caused accidental navigation. Narrowed to ~15% each side; footer hint rewritten with arrow glyphs plus an "edge taps also turn pages" tip; duplicate `1 / 302` header counter removed in swipe mode; footer bottom padding increased to clear the floating nav.

## Migration notes

None. Backward-compatible gesture and UI fixes. Mobile and desktop rendering paths unchanged except the footer copy and rating button height.
