## Summary

This patch makes the bottom navigation self-explanatory and gives guests a way back to browsing from every auth wall. Nav pills now show icon + label, and every sign-in prompt links back to Explore for guests who don't want an account.

## Changed

- **Labeled nav pills** — Floating nav items now show icon + text label (was icon-only with `aria-label`); active pill highlights with label.
- **Guest escape hatch** — `LoginRequired` cards (Explore, Practice), login/signup forms, and the deck-detail import prompt all link back to Explore via "Continue as guest".

## Migration notes

None. Backward-compatible UI additions; no behavior change for signed-in users beyond visible nav labels.
