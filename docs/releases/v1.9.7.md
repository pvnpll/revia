## Summary

This release brings the AI Mode experience closer to the core application's Spaced Repetition (SRS) mechanics by introducing the **Hybrid Loop Mechanic**. Now, if a learner struggles with an AI-generated card, they are guaranteed to see that exact card again before the session ends. Furthermore, the UI numbering has been updated to reflect the true "endless" nature of the AI generation, and the specific model used for generation is transparently displayed in the session subtitle.

---

## What changed

### Hybrid Loop Mechanic (AI Session Viewer)
- **Immediate Re-queue:** Modified the `handleRate` function in `ai-session-viewer.tsx`. If a user rates a card `1 (Forgot)` or `2 (Hard)`, the card is automatically duplicated and pushed to the end of the `session.cards` queue.
- **Dual Action:** This preserves the traditional mechanical flashcard loop (forcing the user to review the exact same card until they get it right) while *simultaneously* updating the AI context (adding the concept to `struggled`) so future generated batches can provide easier variations.

### Endless Numbering (AI Session Viewer)
- **Subtitle Update:** Because the AI continuously fetches new batches of cards in the background, a fractional denominator (e.g. `4 / 10`) was misleading as the denominator kept growing. 
- **Core App Parity:** Changed the progress indicator to a flat count (`4 practiced`), perfectly matching the Core App's Practice mode UI for endless sessions.

### Model Transparency & Clean UI (AI Session Viewer & Content)
- **Model Subtitle:** The `AIModeContent` now syncs the actual `ai.meta.model` returned from the API's SSE `done` event into the session state as `lastModel`.
- **Dynamic Display:** The session subtitle dynamically displays the specific model name (e.g., `google/gemma-4-31b-it:free`) instead of a generic `ai` label.
- **Clean Banner:** Removed the redundant "Next batch" button from the session banner, leaving a cleaner UI with just the "Save deck" button, as background pre-fetching handles pagination automatically. Added a `"generating more..."` subtitle state for visual feedback.
