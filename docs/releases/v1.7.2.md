## Summary

This patch makes the app fully usable on desktop browsers and polishes the Explore landing experience. The mobile-only gate is gone — desktop now shows the same phone-width column as mobile — and practice/review sessions, the dashboard, and deck grids all render consistently inside it.

## Changed

- **Desktop shell** — Removed the "Revia is mobile-first" blocker card; the real app now renders on all screen sizes in a centered `max-w-md` column with side shading, borders, and shadow on desktop, full-bleed on mobile.
- **Practice & review viewers** — Fullscreen study overlays (session, loading/error/empty states, review states) constrained to the same centered column on desktop instead of stretching full browser width.
- **Responsive cleanup** — Removed `sm:`/`lg:` breakpoint layouts that fired on desktop viewports inside the narrow column: dashboard stats are a fixed 2-column grid, CTA buttons and auth prompts are full-width stacked, deck grids are single-column, card/lesson forms are single-column.
- **Explore search** — Removed `autoFocus` from both search inputs so mobile browsers no longer pop the keyboard on page load.
- **Public deck cards** — Entire card is now tappable via stretched-link (previously title text only).

## Removed

- **Dead sidebar components** — Deleted unused `AppSidebar` and `LegacyAppSidebar` (nothing imported them).

## Migration notes

None. This is a backward-compatible UI polish release. Mobile rendering is pixel-identical to v1.7.1 (all changes are desktop-only `md:` classes or breakpoint removals inside the fixed-width column).
