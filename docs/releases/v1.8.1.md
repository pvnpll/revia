## Summary

This patch ships the six-item UI polish batch: viewer header always shows Back + theme toggle, header loading skeletons, keyboard focus states on deck/search rows, a 44px title-edit touch target with retry-safe saves, accurate guest lesson copy, and a calmer guest practice landing.

## Changed

- **Study viewer header** — Back button and theme toggle now render together (was either/or); title block truncates safely on narrow screens.
- **App header loading** — Auth-loading spacer replaced with skeleton pills (no more layout shift on first paint).
- **Keyboard focus** — Public deck cards show a focus ring via `focus-within`; library search rows get hover + focus-visible states.
- **Title editing** — Pencil button enlarged to 44px (`h-11 w-11`); failed saves keep the editor open for retry instead of closing.
- **Guest lesson copy** — "Browse cards" corrected to "practice its cards" (tapping starts practice).
- **Guest practice landing** — "Browse public decks" CTA grouped with an "or unlock your own library below" divider; login card retitled "Sign in for your library".

## Migration notes

None. UI-only polish; no API, schema, or behavior changes.
