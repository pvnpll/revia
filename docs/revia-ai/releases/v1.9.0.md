## Summary

This release introduces **Ollama Cloud** (`OllamaCloudProvider`) as a first-class AI provider alongside Gemini and OpenRouter. It implements the standard `AIProvider` contract, connects to the official Ollama Cloud API (`https://ollama.com/api/chat`), uses native structured JSON output (`format: "json"`), includes a free cloud candidate model cascade led by `gemma4:31b` as the default model, and integrates cleanly into the provider factory and fallback orchestration.

---

## What Changed

### 1. OllamaCloudProvider
- Created `src/lib/providers/ai/ollama-cloud-provider.ts` implementing `AIProvider`.
- Communicates directly with the official Ollama Cloud API endpoint (`POST https://ollama.com/api/chat`).
- Uses Bearer authentication with `OLLAMA_API_KEY`.
- Leverages Ollama's native `"format": "json"` mode to ensure structured JSON output.
- Features free candidate model cascade (`gemma4:31b`, `gpt-oss:120b`, `gpt-oss:20b`, `nemotron-3-nano:30b`, `nemotron-3-super`, `nemotron-3-ultra`).
- Maps token usage (`prompt_eval_count` -> `promptTokens`, `eval_count` -> `completionTokens`).
- Handles timeouts (25s default), HTTP status codes (401/403, 404, 429, 5xx), and strips markdown codeblock ticks if present.

### 2. Provider Factory & Selection
- Updated `src/lib/providers/ai/provider-factory.ts` to support `providerName = "ollama"`.
- Setting `AI_PROVIDER=ollama` routes requests directly to `OllamaCloudProvider`.
- Existing `AI_PROVIDER=gemini` and `AI_PROVIDER=openrouter` remain completely unchanged.

### 3. Validation & Types
- Added `"ollama"` to `z.enum(["gemini", "openrouter", "ollama"])` in `src/lib/validators/ai/generation-request.ts`.
- Updated `src/features/ai/types/ai-session.ts` to include `"ollama"` in the provider union.

### 4. Generation Service & Fallback
- Extended `AIGenerationService` in `src/lib/services/ai/ai-generation-service.ts` so when Ollama is selected as primary, fallback can automatically route to Gemini or OpenRouter if configured.

### 5. Environment & Documentation
- Documented `OLLAMA_API_KEY`, `OLLAMA_BASE_URL`, and `OLLAMA_MODEL` in `.env.example`.
- Updated `docs/revia-ai/03-provider-abstraction.md`.

### 6. AI Generator UI Option
- Added **Ollama Cloud** (`Cloud` icon) to the `PROVIDERS` segmented control in `src/features/ai/components/ai-generator-form.tsx`, enabling users to select Ollama Cloud directly in the app.
