## Summary

Fixes the rating footer overlapping the card and restores native vertical scrolling inside revealed cards. Swipe gestures no longer hijack scrolls that start inside the answer pane, and long text wraps and scrolls inside the card bounds.

---

## What Changed

### Shared Viewer (`study-card-viewer.tsx`)
- `handleSwipePointerDown` now bails out when the touch target is inside a scrollable answer pane, so the browser scrolls natively instead of the card capturing the pointer for a swipe.
- `handleSwipePointerMove` releases the drag as soon as a revealed card's gesture turns vertical; horizontal drags still swipe.
- Wired `answerScrollRef` to the swipe revealed pane (previously only attached in ratings mode) and added `touch-pan-y overscroll-contain` to the swipe card wrapper.
- Hint footer renders only when the card is not revealed, so revealed state shows exactly one footer (rating) and never crowds or overlaps the card.
- All card bodies use `min-h-0 flex-1 overflow-y-auto` with responsive text sizes (`text-2xl sm:text-4xl`) and `break-words + overflow-wrap:anywhere` so long strings wrap and scroll inside the card.
