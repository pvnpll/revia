## Summary

UI-only patch that makes the Revia AI section consistent with the regular app UI and fixes session-viewer UX bugs: double padding/scroll from conflicting containers, infinite card wrap on rating, unstable card ids breaking reveal state, missing first-batch loading state, repeated background prefetch from unstable callback deps, and save-deck modal layering/accessibility gaps.

---

## What Changed

### 1. Generator Form (`ai-generator-form.tsx`)
- Page header now matches Practice/Explore/Decks: `h1.text-2xl` with inline Lucide `Bot` icon and muted subtitle (removed oversized `h-12 rounded-2xl` hero block).
- Quick suggestions use `Sparkles` Lucide icon instead of `✨` emoji; added `shadow-sm`, focus ring, and `disabled` state while generating.
- Provider / Difficulty / Batch segmented controls share one style (`rounded-lg bg-muted p-1`, `shadow-sm` active, `min-h-9` targets) with `role="group"`, `aria-pressed`, and `aria-labelledby`; provider buttons use `Zap`/`Sparkles` icons instead of `⚡/✨` emoji.
- Level/Batch grid changed from fixed `grid-cols-2` to `grid gap-3 sm:grid-cols-2` so 360px phones don't crush labels.
- Options checkboxes use `h-4 w-4 accent-primary` with `min-h-9` rows, stacked on mobile.
- Validation and API errors use `role="alert"` and standard `rounded-xl` error block; provider-key tip covers both `GEMINI_API_KEY` and `OPENROUTER_API_KEY`.
- Submit button loading copy shortened to `Generating cards...` with `aria-live`; removed manual `gap-2` (Button already provides gap); removed `CardHeader pb-4` override.

### 2. Mode Content (`ai-mode-content.tsx`)
- Removed `container max-w-lg py-6 px-4 pb-24` wrapper — `AppShell` already provides `max-w-md px-4 py-5`, so the AI form was double-padded and wider than every other page.
- Added first-batch streaming state: when a session exists but `cards.length === 0` and streaming is active, show topic/goal header plus a progress `Card` (spinner, Cancel, error) instead of flashing back to the form.
- Fixed `handleNextBatch` dependency array (`[session, ai]` → granular fields + `ai.generate`/`ai.isStreaming`) so the near-end background prefetch doesn't re-fire every render.

### 3. Session Viewer (`ai-session-viewer.tsx`)
- Replaced `flex flex-col min-h-screen` + custom `border-b bg-card/50 backdrop-blur` action bar with `space-y-4` page layout: back link + `h1` title/goal, then a single `Card` toolbar with `Badge` (level), `Badge` (progress `n / total`), card count/provider meta, and `ms-auto` Save/Next actions.
- Rating advance clamps on the last card (`Math.min(index + 1, len - 1)`) and passes `noLoop` to `StudyCardViewer` instead of modulo wrap, matching review clamping and keeping appended-batch + reveal state stable.
- Study-card ids are now stable (`ai-card-{topic}-{level}-{idx}`) instead of embedding `card.front`, which churned `current?.id`-keyed reveal state when fronts duplicated or changed.
- Subtitle now carries live progress (`{progress} · AI batch`); error uses standard `rounded-xl role=alert` block; labels sentence-cased; icons `aria-hidden`; removed unused `LearnerContext` import.

### 4. Save Deck Modal (`save-deck-modal.tsx`)
- Raised from `z-50` to `z-[100]` (matches practice/review overlays), dimmed with `bg-foreground/40`, bottom-sheet on mobile (`items-end sm:items-center`), `shadow-xl`.
- Added proper dialog semantics (`role="dialog" aria-modal`), backdrop-click and `Escape` to close, autofocus on title input, and `stopPropagation` on the card.
- `Download` icon → `Save`; success color `text-green-500` → `text-green-600 dark:text-green-500`; footer stacks `flex-col-reverse` with full-width mobile buttons; title/label sentence case; error uses `role="alert"`.
