## Summary

The AI card session now opens in the exact same fullscreen swipe viewer as Practice/Review instead of an embedded ratings-mode panel, so swipe gestures, drag deck, headers, and footers are fully consistent with the old UI.

---

## What Changed

### 1. Session Viewer (`ai-session-viewer.tsx`)
- Renders `StudyCardViewer` with `navigationMode="swipe" fullscreen noLoop allowFreeNavigation` inside a `document.body` portal (`AISessionOverlay`, same pattern as `PracticeOverlay`), producing the shared fixed `inset-0 z-[100] max-w-md` column with `h-14` header, swipe deck, hint footer, and rating footer.
- Removed the custom page-level `New goal` h1 and `Card` toolbar that duplicated the viewer header and stole vertical space.
- Save deck / Next batch moved into a slim banner row under the shared viewer header (`border-b bg-card/50`); next-batch error renders as a second banner row.
- Swipe moves index-only (`handleSwipeMove`); 1–5 ratings update learner context and clamp advance on the last card.
- Subtitle now `progress · level · provider` (e.g. `3 / 10 · beginner · OpenRouter`).

### 2. Shared Viewer (`study-card-viewer.tsx`)
- Added optional `banner` prop rendered directly below the header; the header itself is unchanged (only added `truncate` to the subtitle line).
- Practice and Review pass no `banner`, so their output is byte-identical.
