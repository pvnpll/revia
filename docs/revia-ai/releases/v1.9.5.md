# Revia AI Release: v1.9.5

**Date:** 2026-09-24
**Type:** Critical Infrastructure & Reliability Fix

## Overview

Resolved the root cause of the dashboard HTTP 500 error and card generation failures caused by Supabase session pooler exhaustion (`EMAXCONNSESSION: max clients reached in session mode - max clients are limited to pool_size: 15`), and made learner context database queries resilient to prevent generation aborts.

## Changes

### 1. Database Connection Pooler Configuration (`prisma.ts`)
- Automatically translates Supabase session pooler connections on port `5432` to the transaction pooler on port `6543` (PgBouncer).
- Appends `connection_limit=1` and `pgbouncer=true` to guarantee serverless lambda invocations on Vercel never exhaust the 15-client session connection limit.

### 2. Resilient Context Service (`ai-context-service.ts`)
- Wrapped learner context database queries in graceful try/catch blocks with default schema fallback so temporary database connection latency or pool exhaustion never causes card generation streams to fail with unexpected errors.
