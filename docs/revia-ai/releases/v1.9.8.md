## Summary

This release is a retroactive documentation of a performance optimization pushed to production. To reduce the 5-8 second Time-To-First-Token (TTFT) latency when generating large JSON arrays using heavy models (like `gemma-4-31b`), the default card generation batch size was halved from 10 to 5.

---

## What changed

### Generation API Optimization (`ai-mode-content.tsx`)
- **Batch Size Reduction**: Default `batchSize` was changed from `10` to `5`. This mathematically halves the required generation time for the provider before the stream resolves the JSON block.
- **Prefetch Threshold Tuning**: The background prefetch threshold `cardsRemaining` was adjusted from `<= 6` to `<= 3`. When the user is halfway through a 5-card stack, the app silently triggers the next batch fetch, ensuring the 2.5-4 second latency is entirely hidden behind user swiping time.

## Verification
- Verified AI Mode generates 5 cards initially and smoothly prefetches the next 5 when reaching the 2nd card in the stack.
